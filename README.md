# OG MARKETS Professional Render Project

Includes responsive trading-style client site, dashboard, demo markets, demo trading, demo deposit/withdrawal workflows, transactions, customer/admin chat, admin panel, logo, favicon, SQLite database and Render configuration.

Pydroid 3: `pip install -r requirements.txt` then `python app.py`.

Render build: `pip install -r requirements.txt`
Render start: `gunicorn app:app`

Demo admin: admin@ogmarkets.local / ChangeMe123!

This is a demo/prototype. It does not execute real-money trades or process real deposits/withdrawals. Real brokerage operation requires appropriate regulatory, KYC/AML, payment, banking, market-data, broker/liquidity and security arrangements.
